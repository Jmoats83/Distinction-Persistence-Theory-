# Distinction–Persistence Theory (DPT)

This repository contains the written foundations for Distinction–Persistence Theory, including axioms, formalism notes, bridge documents, and preprint material.

## Current focus

To turn DPT from an analysis framework into an accountable system, the next implementation priority is:

## 🔥 Prediction Engine (Forecast & Lock)

**Why first:** prediction creates skin-in-the-game and measurable track records.

A Forecast & Lock workflow should:

1. Accept a dated claim (`Will X happen by Y?`).
2. Score current state with DPT axes.
3. Emit a probability estimate plus compact rationale.
4. Define explicit falsification conditions.
5. Hash and timestamp-lock the prediction.
6. Append to a public immutable-style ledger file.
7. Re-evaluate automatically at resolution date.

This creates accountable outputs instead of open-ended commentary.

## Follow-on priorities

### 2) Counterfactual Engine
For any claim: **what must change for the result to flip?**

- Required variable movement
- Constraint weakening/strengthening
- Environmental opposition changes

This guards against confirmation bias and overfitting narrative explanations.

### 3) Persistence Map
Graph model connecting claims, entities, events, evidence, and predictions with typed edges:

- Support
- Opposition
- Reinforcement
- Decay

This surfaces stable narrative structures vs. fragile clusters.

## Strategic order

If only one can ship first: **Prediction Engine**.

It is the shortest path from “interesting framework” to “track-recorded theory.”
