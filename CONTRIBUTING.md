# Contributing

This repository is currently curated to preserve a clean axiomatic spine.

If you want to contribute:
1. Open an issue describing the proposed change.
2. Keep claims separated from derivations.
3. Prefer minimal knobs and falsifiable commitments.
4. Add citations when referencing existing literature.

Style goals:
- Transmission-safe writing
- Clear boundaries between: definitions / theorems / conjectures / interpretation
